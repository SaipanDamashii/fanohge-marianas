# Fanohge — The Marianas (web build)

A playable HTML5/Three.js build of the game. Open `index.html` in any modern
browser (Chrome/Edge/Firefox recommended). Everything runs client-side — no
server, no install.

## Host on GitHub Pages
1. Push this folder's contents to a GitHub repo.
2. GitHub → Settings → Pages → deploy from the `main` branch `/` root.
3. Visit `https://<you>.github.io/<repo>/`.

The `.nojekyll` file is included so GitHub Pages serves it as-is.

## Notes
- 3D board requires WebGL.
- Toggle sound with the 🔊 button (browsers require a first click before audio).
